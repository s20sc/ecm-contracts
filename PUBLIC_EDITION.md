# Scope and provenance of this public edition

This is a publication-oriented derivative of the archived research package. It is not a claim that newly edited bytes existed at the historical freeze date. The archive remains preserved separately.

The edition uses neutral adjudicator identifiers and replaces author-machine path prefixes in execution metadata with documented placeholders. This exact-prefix projection also applies to author-machine paths inside historical notes; it preserves their scientific judgments, failed-read explanations and negative results. Upstream source quotations and other authors’ paths are unchanged. It removes machine-specific launch/queue wrappers while preserving their relevant model and execution settings in METHODS.md. Scientific prompts, decisions, exclusions, unresolved findings, negative results and model-generation disclosures are retained. Source quotations and third-party files must not be silently rewritten as part of a naming cleanup.

Current publication manifests bind the files distributed in this edition. Original hashes and event times in historical amendment/provenance records remain historical evidence. A separate derivation inventory identifies the publication transformations and their source/output hashes; its existence does not establish label validity or prove past blinding. Validation must compare the complete results and per-case records against the archive under only explicitly declared representation mappings.

The source browser under sources/ provides the retained files used by the later source-replay workflows in their original project-relative paths, plus an index of all source snapshots. It is explicitly a selection, not every file of every upstream repository. Original copyright and license notices remain applicable.

The full content-addressed snapshot archive is REQUIRED as a separate offline input for the complete historical numerical replay; downloading it is unnecessary when only browsing the code or selected source view. It is not a replacement for browsable code/data/documentation. One upstream project includes its own AGENTS.md, confirmed byte-identical at the recorded commit; the public selected source view does not need that unrelated project-maintenance document. The original full snapshot must not be presented as byte-identical if files are removed.

The publication file inventory and the accompanying validation receipts identify the distributed representation. The snapshot asset remains a separate required input for the full historical numerical replay; its availability must be checked at the hosting release. The V56 addition preserves the previously validated primary package byte for byte and has a separate bounded validation record. Successful reproduction does not establish label validity or whole-study scientific acceptance.
